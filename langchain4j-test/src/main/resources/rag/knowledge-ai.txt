RAG(Retrieval-Augmented Generation,检索增强生成)是一种把检索和生成结合的技术:先从知识库中检索与问题相关的内容,再把检索结果作为上下文交给大语言模型生成回答。它能让模型回答训练数据里没有的知识,并减少幻觉。

Embedding(向量化/嵌入)是把文本映射成固定长度浮点数向量的技术。语义相近的文本,向量之间的距离也相近。基于这个性质可以做语义搜索、聚类和推荐。向量维度取决于模型,例如智谱 embedding-3 支持 2048 维。

大语言模型(LLM)是无状态的:每次请求都是独立的,模型本身不会记住之前的对话。聊天应用中的记忆,是通过把历史消息随每次请求重新发送来实现的。

Transformer 是当前大语言模型的基础架构,2017 年由论文《Attention Is All You Need》提出。它的核心是自注意力机制(Self-Attention),让模型在处理每个词时都能关注上下文中所有其他词。

智能体(Agent)是能够感知环境、调用工具、自主规划并以循环方式完成任务的 AI 系统。典型的 Agent 循环是:思考、选择工具、执行工具、观察结果、继续思考,直到得出最终答案。

Function Calling(函数调用/工具调用)是大语言模型 API 提供的能力:开发者向模型描述可用的函数及其参数,模型在需要时返回结构化的函数调用请求,由应用在本地执行后,再把结果回传给模型继续推理。

幻觉(Hallucination)指大语言模型生成看似合理但事实上错误的内容。缓解手段包括:用 RAG 让模型基于检索到的资料回答、降低 temperature、以及在提示词中明确要求模型不要编造。
